## CORE

- 新增 `Utils::printError`、`Utils::getErrorDetails`，以及 `ApiException::getResponseDetails()`、`getDiagnosticCode()`、`getDiagnosticMessage()`，可直接输出或读取错误的 HTTP 状态码、请求 ID、响应头、响应正文快照和原因链；原有 getter 行为保持不变。
- 重试判断会沿 `getPrevious()` 识别包装后的业务错误码；请求取消和 TLS 证书或握手错误会终止重试；凭证过期时先失效凭证缓存，再重新获取凭证并签名。
- AssumeRole、OIDC、SAML 凭证请求统一错误诊断和凭证校验；凭证交换不再因凭证过期类错误码本身重试。
- 修复 PHP 5.5 下凭证刷新失败导致的崩溃，并保留异常链。
